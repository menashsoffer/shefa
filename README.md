# מוקד שפ״ע אריאל — תמונת מצב

אתר יחיד, self-contained: מפה כקנבס מלא־מסך עם שכבות מידע צפות, 5 מדדי־על,
סינון צולב, ומצב סיפור בן 7 תצוגות לישיבת בוקר.

## הרצה

הקובץ `index.html` עצמאי לחלוטין (הספריות והנתונים מוטמעים). אפשר פשוט לפתוח אותו:

```bash
open index.html
```

או דרך שרת מקומי (מומלץ):

```bash
npm run serve      # → http://localhost:8777
```

הבקשות החיצוניות היחידות בזמן ריצה: אריחי מפת OpenStreetMap (עם נפילה אוטומטית
לקו גבול השיפוט אם אין רשת), וגופני Google (עם fallback לגופן מערכת).

## בנייה מחדש מהנתונים הגולמיים

```bash
npm install                    # xlsx (ל-build.js בלבד)
npm run build                  # build.js -> dist/site_data.json ; assemble.js -> index.html
```

`build.py` הוא מימוש־מראה ב-pandas (ראה DECISIONS.md §2):

```bash
python3 -m pip install pandas openpyxl && python3 build.py
```

## נחמן — העוזר הווירטואלי

כפתור `🤖 נחמן` בפינה הימנית התחתונה פותח פאנל שאלות־תשובות על הנתונים.
בפתיחה הוא מציג את **80 השאלות שהוא יודע לענות עליהן**, מקובצות לפי נושא —
לחיצה על שאלה שולחת אותה.

שלושה סוגי שאלות: **כמותיות** (`כמה חריגות בתברואה?`), **הגדרות**
(`מה זה חריגת SLA?`, מתוך `data/wiki/`), ו**פתוחות** (`ספר לי את תמונת המצב` —
מריץ את התצוגה המתאימה במצב סיפור).

תשובה כמותית מחילה גם את הסינון המתאים ומזיזה את המפה, כך שהלוח כולו מציג את
מה שנשאל. אפשר לכבות במתג בתוך הפאנל. הגרפים אינם נפתחים אוטומטית.

**הכול מקומי.** אין רשת, אין מפתח API, אין מודל. כל מספר מחושב בדפדפן דרך אותו
`filtered()` שמזין את ה־KPI והגרפים, ותחת כל תשובה מוצגת שורת "מסנן:" שמראה
בדיוק לפי מה נספר. עובד גם בלחיצה כפולה על `index.html` בלי שרת ובלי רשת.
